# Sua Essência Moda — site vitrine

Site: https://suaessenciamodaplus.com.br

## Como atualizar o site
1. Faça as alterações no VS Code e salve.
2. Clique no ícone de galho (Controle do Código-Fonte).
3. Escreva uma frase curta (ex.: "novos vestidos") e clique em **Confirmar**.
   Com as configurações da pasta .vscode, o VS Code já sincroniza sozinho após confirmar.
4. Em cerca de 1 minuto o Cloudflare Pages publica a nova versão.

## Estrutura
- index.html — página completa (textos, produtos e imagens)
- favicon.* — ícones da aba do navegador
- .vscode/settings.json — configura o VS Code para publicar com um clique
